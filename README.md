# Peekashade — website

Static site (no build step) for Peekashade, published with GitHub Pages from the `main` branch.

Generated by `websites/make_site.py peekashade` in the games working tree — don't hand-edit if it will be regenerated.

- `index.html` — home: screenshots, video, how it works, where to play, notes for parents
- `privacy.html` — privacy policy (the URL App Store Connect asks for)
- `support.html` — support (the other URL it asks for)
