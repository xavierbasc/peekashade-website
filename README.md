# Peekashade — website

Sitio estático (sin build) de Peekashade, publicado con GitHub Pages desde la rama `main`.

Se genera con `websites/make_site.py peekashade` del árbol de trabajo de los juegos: no editar a mano si se va a regenerar.

- `index.html` — portada (capturas, vídeo, para quién es, para padres)
- `privacy.html` — política de privacidad (la URL que pide App Store Connect)
- `support.html` — soporte (la otra URL que pide)
